## Ejercicio 1

### Parte A

#### 1. Generalización simbólica

*¿Cuáles son las reglas escritas del lenguaje?*

JavaScript es un lenguaje que permite utilizar el paradigma de programación estructurada. Sus reglas escritas están determinadas por su sintaxis y por las construcciones que ofrece el lenguaje para representar algoritmos.

Entre ellas se encuentran:

* La declaración y utilización de variables mediante let y const.
* Los diferentes tipos de datos.
* Los operadores aritméticos, lógicos y de comparación.
* Las estructuras condicionales como if, else y switch.
* Las estructuras repetitivas como for, while y do...while.
* La definición de funciones para dividir un programa en partes más pequeñas y reutilizables.

Estas instrucciones pueden organizarse en bloques mediante llaves { }, siguiendo las reglas sintácticas establecidas por el lenguaje.

En el contexto de la programación estructurada, estas construcciones permiten organizar los programas mediante *secuencias, decisiones y repeticiones*, evitando depender de saltos arbitrarios en el flujo de ejecución.


#### 2. Creencias de los profesionales

*¿Qué características particulares del lenguaje se cree que sean "mejores" que en otros lenguajes?*

Entre las características de JavaScript que suelen considerarse ventajas frente a otros lenguajes se encuentra su facilidad de aprendizaje inicial y su amplia utilización.

Además, permite ejecutar código directamente en los navegadores web, lo que facilita el desarrollo de aplicaciones y páginas interactivas.

También cuenta con:

* Una comunidad muy grande.
* Abundante documentación.
* Una gran cantidad de bibliotecas y herramientas.
* Flexibilidad para resolver diferentes tipos de problemas.
* Posibilidad de utilizarlo tanto en programas pequeños como en aplicaciones de mayor complejidad.

Por estas características, JavaScript es considerado un lenguaje accesible, ampliamente utilizado y con muchas posibilidades de aplicación.


### Parte B

#### 1. ¿Tiene una sintaxis y una semántica bien definida? ¿Existe documentación oficial?

Sí. JavaScript posee una sintaxis y una semántica formalmente definidas mediante el estándar *ECMAScript*, que establece las reglas del lenguaje.

Además, existe documentación oficial y documentación de referencia que describe sus características y funcionamiento.


#### 2. ¿Es posible comprobar el código producido en ese lenguaje?

Sí. El código JavaScript puede comprobarse mediante diferentes mecanismos.

Los motores del lenguaje pueden detectar errores de sintaxis y, durante la ejecución, pueden detectarse errores mediante excepciones.

Además, existen herramientas de análisis estático, como los *linters, y herramientas de **testing* que permiten verificar el comportamiento del programa antes y durante su ejecución.


#### 3. ¿Es confiable?

JavaScript puede utilizarse para desarrollar software confiable, ya que posee mecanismos para detectar y manejar errores y existen herramientas para realizar pruebas y analizar el código.

Sin embargo, la confiabilidad no depende únicamente del lenguaje, sino también de la forma en que el programador desarrolla, prueba y mantiene el programa.

Debido a su flexibilidad, algunas características del lenguaje pueden producir comportamientos inesperados si no se utilizan correctamente.


#### 4. ¿Es ortogonal?

JavaScript posee un cierto grado de ortogonalidad, ya que muchas de sus características pueden combinarse entre sí.

Sin embargo, no es completamente ortogonal, debido a que presenta excepciones y comportamientos particulares en determinadas situaciones.

Por lo tanto, se puede considerar que tiene una *ortogonalidad parcial*.


#### 5. ¿Cuáles son sus características de consistencia y uniformidad?

JavaScript presenta consistencia en varias de sus estructuras básicas, especialmente en aquellas utilizadas en programación estructurada, como las estructuras condicionales, repetitivas y las funciones.

Sin embargo, no es completamente uniforme, ya que el lenguaje ha evolucionado durante muchos años y mantiene características de diferentes etapas de su desarrollo.

Esto hace que existan distintas formas de realizar algunas operaciones y ciertos comportamientos particulares.


#### 6. ¿Es extensible? ¿Hay subconjuntos de ese lenguaje?

Sí, JavaScript es extensible. Puede ampliarse mediante bibliotecas, módulos y otras herramientas que incorporan nuevas funcionalidades.

También es posible trabajar con subconjuntos o versiones acotadas del lenguaje.

En este caso, el propio análisis se realiza considerando *JavaScript acotado al paradigma de programación estructurada*, utilizando solamente las características necesarias para dicho paradigma y dejando de lado aquellas relacionadas con otros paradigmas.


#### 7. El código producido, ¿es transportable?

Sí, el código JavaScript es altamente transportable, ya que puede ejecutarse en diferentes sistemas operativos y dispositivos siempre que exista un entorno compatible, como un navegador web o un motor de JavaScript.

Sin embargo, pueden existir algunas diferencias cuando el código depende de características específicas del entorno en el que se ejecuta.
